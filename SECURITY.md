# Сообщение об уязвимости

Предпочтительный приватный канал — **Security → Report a vulnerability** в репозитории GitHub после включения Private vulnerability reporting владельцем. Если кнопка недоступна, запросите приватный канал у сопровождающего без описания уязвимости в публичном Issue.

Укажите версию Music Player и Windows, шаги воспроизведения и предполагаемые последствия. Для примера используйте синтетические файлы. Удалите токены, персональные данные и локальные пути из вложений.

[Инструкция по приватным сообщениям GitHub](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
