# Music Player 0.2.0 для Windows x64

## Запуск и демонстрация

1. В Проводнике выберите **Извлечь всё** для `MusicPlayer-0.2.0-win-x64.zip`. Сохраните все файлы распакованной папки рядом друг с другом.
2. Откройте **Music Player.exe** в папке **Music Player 0.2.0**. В архиве уже есть Electron и все runtime-зависимости. Для запуска достаточно Windows x64.
3. Нажмите **Выбрать папку**, укажите **Demo audio** или папку с разрешёнными MP3 и FLAC. В демонстрационной папке два коротких синтетических тона с тестовыми тегами.
4. Найдите треки по запросу `fixture album` и отсортируйте по длительности. Запустите оба формата из таблицы. Покажите паузу, перемотку, следующий трек и кнопку **Без звука**. Отметьте трек сердцем и нажмите **Моя волна**. Выберите строку в таблице, чтобы вернуться к последовательной очереди.
5. Создайте плейлист с обоими треками, переставьте их и запустите плейлист. В библиотеке выберите режим **Открытия** рядом с кнопкой **Моя волна**.
6. Измените громкость, закройте окно и запустите приложение повторно. Проверьте порядок треков в плейлисте, режим «Волны», лайк и громкость. Для демонстрации разницы режимов используйте более длинный каталог. При двух доступных треках «Волна» после первого выбора чередует их.

## Ручная проверка на машине показа

- [ ] Сравнить SHA-256 ZIP с опубликованной рядом суммой через `Get-FileHash .\MusicPlayer-0.2.0-win-x64.zip`. При первом запуске записать версию Windows и реакцию SmartScreen или политики организации.
- [ ] Распаковать в каталог с пробелами, запустить в новом профиле Windows и проверить пустую библиотеку. Отключить сеть до запуска и оставить её отключённой на время сценария.
- [ ] Выбрать папку через системный диалог, проверить MP3, FLAC, теги и слышимый звук. Повторить импорт и проверить отсутствие дублей. Сравнить контрольные суммы аудио до и после.
- [ ] На разрешённых файлах со встроенными JPEG или PNG проверить обложки в таблице и в плеере. У демотреков без обложек отображается значок ноты. Проверить поиск, сортировку и регулятор громкости в окне минимальной ширины.
- [ ] Поставить лайк, запустить «Волну», перейти к следующему треку и дождаться автоматического перехода. С одним доступным треком очередь должна остановиться. При недоступных источниках должно появиться сообщение.
- [ ] Создать и переименовать плейлист, добавить композиции, изменить их порядок и проверить очередь. Убрать одну композицию и проверить её в библиотеке. Закрыть приложение, переместить один тестовый файл и проверить пометку о недоступности и воспроизведение остальных треков.
- [ ] Закрыть окно, перенести распакованное приложение в другой каталог, сохранив папку музыки на прежнем месте, и запустить снова. Проверить библиотеку, лайк и воспроизведение. Проверить, что `library.sqlite3` находится в `%APPDATA%\Music Player`.
- [ ] Повторно закрыть окно и проверить отсутствие зависших процессов приложения и системных сообщений о сбое.

## Сборка из исходников

Сборка рассчитана на Windows x64 с Node.js 24.22.x и pnpm 11.25.0. Используется Electron 45.3.0 из зафиксированных зависимостей.

```powershell
pnpm install --frozen-lockfile --store-dir .pnpm-store
pnpm exec install-electron
pnpm package:windows
pnpm test:release
```

Первые две команды подготавливают локальный store и Windows-бинарники Electron. Упаковка использует этот store офлайн с `--frozen-lockfile`, production-зависимости раскладываются без install-скриптов. Штатный Windows `tar.exe` создаёт ZIP в `release`. Рядом сохраняется SHA-256. Это переносимый каталог приложения с `resources/app`. Лицензии Electron и Chromium находятся в корне распакованной папки, лицензии runtime-пакетов входят в их каталоги.

## Проверка обновления с 0.1.1

```powershell
$env:MUSIC_PLAYER_011_ZIP = (Resolve-Path .\release\MusicPlayer-0.1.1-win-x64.zip).Path
pnpm test:release
Remove-Item Env:MUSIC_PLAYER_011_ZIP
```

Тест запускает старый EXE во временном профиле, импортирует синтетические треки и сохраняет лайки, историю, громкость и отключение звука. Затем он открывает тот же профиль в 0.2.0 и сверяет схему, данные существующих таблиц и воспроизведение в режиме **Баланс**.

## Известные ограничения

- Сборка ориентирована на Windows x64 и демонстрационный каталог. У пакета нет подписи издателя Music Player. SmartScreen и политики организации могут повлиять на запуск.
- SQLite и профиль хранятся в `%APPDATA%\Music Player`, отдельно от распакованного приложения. Библиотека ссылается на исходные файлы по локальным путям. Для переноса музыки на другой компьютер потребуется импорт на нём.
- Версия 0.2.0 обновляет схему профиля с 3 до 4. Для возврата к 0.1.1 понадобится резервная копия базы со схемой 3 или отдельный профиль. [Миграции и резервное копирование](PERSISTENT_LIBRARY.md#миграции-и-запись-данных).
- Обложки читаются из встроенных JPEG и PNG с ограничениями по размеру. Производительность на больших каталогах пока не измерялась.
- Алгоритм использует эвристические веса. Короткий каталог ограничивает выбор. Для оценки попадания во вкус нужен пилот с участниками.
