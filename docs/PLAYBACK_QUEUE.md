# Воспроизведение и очередь в Music Player 0.3.0

В нижней панели **Очередь** показывает текущую композицию и ожидающие элементы. Кнопки **↥** и **＋** в библиотеке и плейлистах помещают трек в начало или конец ожидания. В очереди можно запустить ожидающий трек, переместить его на одну позицию, удалить или очистить все ожидающие элементы. У текущего трека при редактировании сохраняются звук и позиция. Один трек можно добавить несколько раз.

## Переходы

| Действие | Результат |
| --- | --- |
| Выбор строки библиотеки | Создаёт снимок библиотеки в порядке импорта и начинает с выбранной строки. Поиск и сортировка влияют на таблицу. Более ранние строки доступны через **Предыдущий трек** и в следующем цикле Repeat All. |
| Запуск плейлиста | Заменяет очередь снимком плейлиста. Очередь можно редактировать независимо от сохранённого плейлиста. |
| Запуск «Моей волны» из конечной очереди | Начинает радио с новой рекомендацией. Повторное нажатие в режиме радио продвигает текущую очередь. |
| Выбор ожидающего элемента | Запускает этот элемент и сохраняет остальных в порядке ожидания. |
| Предыдущий трек | Возвращает последний проигранный элемент текущего цикла. При пустой истории в библиотеке можно перейти к более ранней строке исходного порядка. Уходящий проигранный элемент возвращается в начало ожидания. |
| Следующий трек | Берёт первый ожидающий элемент, затем применяет правила повтора или запрашивает рекомендацию. |
| Недоступный источник | Плеер пытается открыть следующий элемент в направлении перехода. При переборе доступен максимум один новый цикл Repeat All. Если воспроизвести ничего не удалось, отображается ошибка. |

## Shuffle и Repeat

- **Shuffle** переставляет ожидающие элементы исходного списка. Текущий трек и уже пройденные элементы остаются на своих местах. Ручные элементы сохраняют свои позиции при перемешивании. Отключение восстанавливает основной порядок среди ожидающих элементов с учётом вставок, перемещений и удалений. При перемещении в Shuffle основной порядок запоминает положение перемещённого элемента относительно выбранного соседа.
- **Repeat Off** останавливает конечную очередь после последнего трека.
- **Repeat All** начинает новый цикл по основному списку с учётом правок. С включённым Shuffle новый цикл перемешивается и при наличии альтернативы начинается с другого элемента. История переходов начинается заново. Очистка ожидания убирает ожидавшие элементы также из следующих циклов. Пройденные и текущий остаются в списке повтора.
- **Repeat One** повторяет текущий элемент после естественного окончания. Следующий, предыдущий и выбор ожидающего элемента выполняются по обычным правилам ручного перехода. У каждого повтора новая сессия прослушивания.
- **«Моя волна»** воспроизводит ручные элементы до запроса очередной рекомендации. Shuffle в радио отключён, настройка для конечных очередей сохраняется. Off и All оставляют радио непрерывным при наличии других кандидатов. One применяет явный повтор текущего элемента. При единственном доступном кандидате радио после его окончания ждёт явного запуска или ручной вставки, если One выключен.

Плеер запрашивает следующую автоматическую рекомендацию после записи истории предыдущего трека. Правки очереди и смена режима «Волны» сами по себе не создают событий прослушивания. Естественный переход записывает только результат прослушивания. Отказ источника записывает ошибку. [Правила событий](LISTENING_FEEDBACK.md).

## Сеанс и управление

SQLite сохраняет источник, ID текущего элемента, порядок, историю переходов и режимы. Позиция сохраняется при паузе, перемотке и примерно каждые пять секунд звучания. При открытии приложение показывает восстановленный сеанс. Кнопка **Воспроизвести** открывает источник и продолжает с сохранённой позиции. До команды пользователя аудиофайл не открывается. Отсутствующие файлы помечаются в очереди. Максимальный размер очереди — 50 000 элементов, глубина навигации назад в радио — 100 треков.

**Пробел** переключает воспроизведение, **Alt+←** и **Alt+→** выполняют переходы. Команды окна уступают фокусу полей ввода и интерактивных элементов. Через Chromium Media Session плеер передаёт Windows название, исполнителя и альбом и принимает команды воспроизведения, паузы, переходов и перемотки при поддержке платформой. Для физических медиаклавиш результат зависит от маршрутизации активной медиасессии Windows. [Media Session API](https://www.w3.org/TR/mediasession/).

Renderer хранит модель очереди с UUID на каждое вхождение и управляет одним `HTMLAudioElement`. Main валидирует снимок, хранит его в SQLite и разрешает воспроизведение по Track ID через существующий API источников. [Миграция и восстановление базы](PERSISTENT_LIBRARY.md#миграции-и-запись-данных).

## Отложено

- P2 — обмен M3U/M3U8. Требуется определить сопоставление путей со стабильными ID, представление пропавших источников и политику дубликатов при импорте в сохранённые плейлисты.
