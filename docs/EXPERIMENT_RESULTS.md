# Результаты сравнения рекомендаций

## Статус пилота

Пользовательский пилот ещё не проводился. Фактических оценок музыкального вкуса, ответов о знакомстве и данных о числе добровольцев пока нет. Процедура, формат результатов и команды проверки описаны в [протоколе эксперимента](RECOMMENDATION_EXPERIMENT.md).

## Полученные технические данные

Прогон выполнен на Windows x64 с Node.js 24.22.1. Использован встроенный синтетический каталог из 14 записей, из которых 13 доступны, с двумя началами воспроизведения, одним пропуском, одним дослушиванием и одним лайком. Методы формировали по 8 позиций при seed 42–47, фиксированном `now = 1794355200000` и режиме «Баланс». Версии — `random-1`, `likes-1` и `wave-1`.

| Метод | Разнообразие известных исполнителей | Соседние повторы известного исполнителя | Повторы ID внутри списка | Пересечения с недавними на список | Новые по истории | Средняя медиана / средний p95, мс |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Random | 51,2% | 21,9% | 0 | 1,17 | 85,4% | 0,003 / 0,007 |
| Preference Baseline | 42,9% | 63,3% | 0 | 1,33 | 83,3% | 0,006 / 0,012 |
| Personal Wave | 42,9% | 0,0% | 0 | 1,00 | 87,5% | 0,016 / 0,044 |

Строки усредняют шесть запусков каждого метода. Для повторения и получения значений по каждому запуску выполните команду. Замеры времени зависят от машины и нагрузки.

```powershell
node scripts/compare-recommendations.mjs --example 8 42,43,44,45,46,47
```

## Примеры для показа

В регрессионном снимке с историей и seed 42 в режиме «Открытия» на первой позиции появился трек `i` с баллом 4. Совпадение исполнителя дало +2, жанра +1, новизна +1. Фильтры отсеяли пять недавних кандидатов и одного кандидата предыдущего исполнителя. Из трёх оставшихся сработал поиск ещё не слышанных. На второй позиции у трека `a` балл 6. Лайк, исполнитель, жанр и дослушивание дали +6, +2, +1 и +1, пропуск вычел 4. На холодном старте «Знакомое» разрешает равные баллы воспроизводимым перемешиванием. В каталоге из одного трека причина выбора — единственный кандидат.

## Ограничения и выводы

В этом прогоне «Волна» убрала соседние повторы известных исполнителей. Random показал более высокую долю уникальных исполнителей по всему списку. Это разные свойства очереди. Все три метода выбирают без возвращения, поэтому внутри одной очереди дублей ID нет. Повторы при последовательных пересчётах живого радио этим замером не охвачены.

Каталог, реакции и история в техническом прогоне синтетические. Шесть seed проверяют поведение на одном снимке. Вывод о соответствии вкусу возможен после сбора и анализа оценок добровольцев. Для конференции доступны демонстрация фактической трассы, техническое сравнение и готовый протокол слепого пилота.
