# Music Player v0.5.0

Первый публичный выпуск Music Player для Windows x64. Он воспроизводит локальные MP3 и FLAC, показывает теги и обложки, сохраняет библиотеку, плейлисты и очередь. Доступны поиск, сортировка, Shuffle и Repeat.

В версии 0.5.0 «Моя волна» показывает, почему автоматически выбрала трек. В объяснении видны роль режима, учтённые реакции и правила разнообразия. В исходниках есть инструменты сравнения алгоритмов и проведения слепого пилота.

## Windows x64

1. Скачайте `MusicPlayer-0.5.0-win-x64.zip` и `MusicPlayer-0.5.0-win-x64.zip.sha256`.
2. Сравните значение из `.sha256` с результатом `Get-FileHash .\MusicPlayer-0.5.0-win-x64.zip -Algorithm SHA256`.
3. Распакуйте архив целиком и запустите **Music Player.exe**. Папка **Demo audio** содержит два синтетических трека для проверки импорта.

SHA-256 ZIP — `afa9d36233c46818d86b263ea1bba50d9f654964e96cda5071422c2c43cf976a`.

Исполняемый файл без цифровой подписи. На запуск могут влиять SmartScreen и политики Windows. Версия 0.5.0 работает с локальными файлами. Загрузка музыки и интеграции со стриминговыми сервисами пока отсутствуют.
