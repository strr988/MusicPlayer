# Music Player v0.5.0

Первый публичный выпуск исходного кода Music Player. Приложение воспроизводит локальные MP3 и FLAC, показывает теги и обложки, сохраняет библиотеку, плейлисты и очередь. Доступны поиск, сортировка, Shuffle и Repeat.

В версии 0.5.0 «Моя волна» показывает, почему автоматически выбрала трек. В объяснении видны роль режима, учтённые реакции и правила разнообразия. В исходниках есть инструменты сравнения алгоритмов и проведения слепого пилота.

## Исходники и запуск

Исходники доступны в архиве **Source code** на странице выпуска. Готовый Windows ZIP пока недоступен. Сборка и запуск из исходников проверены на Windows x64. [Инструкция запуска](https://github.com/strr988/MusicPlayer/blob/main/README.md#разработка).

Версия 0.5.0 работает с локальными файлами. Загрузка музыки и интеграции со стриминговыми сервисами пока отсутствуют.
