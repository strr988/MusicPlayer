# Что изменилось в mustplay 0.8.0

**Музыка.** В библиотеке нажмите **Добавить папку**. Поддерживаются MP3, AAC (ADTS), M4A/MP4 (AAC), Ogg Vorbis, Opus в Ogg, WebM с Opus/Vorbis, FLAC и WAV PCM. FLAC и WAV PCM сохраняют звук без потерь. ALAC, AIFF и WMA встроенным декодером текущей Windows-сборки не воспроизводятся. Плеер читает файлы напрямую, без конвертации.

**Папки.** Раскройте **Музыкальные папки** в библиотеке. Чтобы сменить папку, исключите старую и добавьте новую. Исключение убирает из медиатеки и очереди треки, которых нет ни в одной оставшейся папке. Текущий трек из исключённой папки остановится. Файлы и история остаются на месте; повторный импорт вернёт исходные ID треков и связи с плейлистами.

**Управление.** Кнопка повтора переключается по кругу: выключен → вся очередь (цветной фон) → один трек (цифра «1»). В «Моей волне» очередь и так пополняется автоматически, поэтому кнопка переключает выключенный повтор и повтор одного трека. «Предыдущий» после трёх секунд сначала перематывает к началу. При следующем нажатии в первые три секунды открывается предыдущий трек, если он есть.

**Режимы и таймер.** Нажмите значок окна в нижнем плеере, чтобы открыть мини-плеер. Наведите указатель на обложку в обычном или мини-плеере и нажмите значок разворота. Таймер сна открывается из нижнего плеера; на весь экран он доступен в **Дополнительно** вместе с диско-режимом. Кнопка звуковых эффектов находится сверху по центру обложки, «Текстомузыка» — снизу по центру.

**Текст.** В разделе **Текст песни** запоминается выбор между чтением и «Текстомузыкой». Цветная кнопка **Следить за текстом** означает, что автопрокрутка включена. В «Текстомузыке» полоса прокрутки скрыта; колесо и клавиатура работают как раньше.

**Курсор.** В **Настройки → Интерфейс → Курсор** выберите mustplay, контрастный или системный курсор Windows. Чтобы добавить готовый пресет, нажмите **Импортировать пресет курсора** и выберите его JSON-файл. Пресет сразу станет активным и сохранится в списке.

Для своего пресета используйте PNG до 64 × 64 пикселей. Координаты x и y задают точку нажатия от левого верхнего угла, начиная с нуля. В поле png вставьте Base64 PNG без префикса. Второе изображение pointer необязательно: если его нет, применяется arrow.

~~~json
{
  "version": 1,
  "name": "Мой курсор",
  "arrow": { "png": "BASE64_PNG", "x": 4, "y": 3 },
  "pointer": { "png": "BASE64_PNG", "x": 4, "y": 3 }
}
~~~

В PowerShell получить строку для поля png можно командой:

~~~powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes((Resolve-Path .\cursor.png).Path))
~~~
