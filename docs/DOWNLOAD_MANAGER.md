# Менеджер загрузок

Анализ и скачивание выполняются в Main последовательно. DownloadManager выбирает провайдер по адресу, проверяет доступность скачивания и сверяет дубли по паре «провайдер, ID записи». Восстановление манифеста использует проверку идентичности соответствующего провайдера. Состояния задачи включают ожидание, анализ, готовность к загрузке, скачивание, обработку, завершение, отмену и ошибку. Renderer обновляет снимок только в открытом разделе. Прогресс использует число полученных байтов и проверенный Content-Length. При отсутствии Content-Length индикатор работает в неопределённом режиме.

Лимиты на профиль составляют восемь сетевых операций в очереди, 100 карточек и 2 ГиБ завершённого аудио. Файл ограничен 150 МиБ. Анализ ограничен 75 секундами, скачивание 10 минутами. До публикации файла можно закрыть карточки отменённых, ошибочных и готовых к подтверждению задач.

Временные файлы создаются в случайном каталоге внутри `music-downloads` в пользовательском профиле. Незавершённый поток имеет расширение `.part`, которое пропускает импортёр библиотеки. При отмене анализа Main завершает дерево yt-dlp, при отмене скачивания останавливает HTTPS-поток. Временный каталог очищается после операции. При следующем запуске Main повторяет очистку каталогов, оставшихся после аварийного завершения.

Перед публикацией Main сверяет размер и SHA-1 с данными источника, проверяет формат и сбрасывает данные файла, манифеста и обложки на диск. Затем Main атомарно переименовывает временный каталог в каталог задачи с UUID. Отмена действует до начала этого переименования. При запуске менеджер восстанавливает опубликованные задачи и сообщает об отсутствующем или укороченном файле. Незавершённые карточки хранятся в памяти.

Импорт сверяет размер и SHA-1 внутри очереди библиотеки, проверяет идентичность файла при чтении тегов и связывает локальный файл и происхождение записи одной транзакцией SQLite. Отмена до транзакции оставляет загрузку доступной для повторного импорта. Повторный импорт возвращает существующий Track ID. Правки метаданных записываются в библиотеку Music Player. Теги аудиофайла не переписываются.

Если загруженный файл перемещён или заменён, библиотека отмечает запись как недоступную. Сканирование папки сохраняет привязку записи к проверенному файлу. Повреждение с сохранением размера обнаруживается при проверке SHA-1 перед импортом. Возобновление частичной загрузки, очистка завершённых карточек и восстановление удалённого оригинала с привязкой к существующему Track ID остаются для следующих версий.
