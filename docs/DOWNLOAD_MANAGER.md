# Менеджер загрузок

Анализ и скачивание выполняются в Main последовательно. Состояния задачи включают ожидание, анализ, готовность к загрузке, скачивание, обработку, завершение, отмену и ошибку. Renderer обновляет снимок только в открытом разделе. Прогресс использует число полученных байтов и проверенный Content-Length. При отсутствии Content-Length индикатор работает в неопределённом режиме.

Лимиты на профиль составляют восемь сетевых операций в очереди, 100 карточек и 2 ГиБ завершённого аудио. Файл ограничен 150 МиБ. Анализ ограничен 75 секундами, скачивание 10 минутами. Можно закрыть карточки отменённых, ошибочных и готовых к подтверждению задач.

Временные файлы создаются в случайном каталоге внутри `music-downloads` в пользовательском профиле. Незавершённый поток имеет расширение `.part`, которое пропускает импортёр библиотеки. При отмене анализа Main завершает дерево yt-dlp, при отмене скачивания останавливает HTTPS-поток. Временный каталог очищается после операции. При следующем запуске Main повторяет очистку каталогов, оставшихся после аварийного завершения.

После проверки оригинала Main атомарно переименовывает временный каталог в каталог задачи с UUID. Там остаются аудио, метаданные и выбранная обложка. Завершённые задачи восстанавливаются при запуске. Незавершённые карточки хранятся в памяти. Импорт связывает локальный файл и происхождение записи одной транзакцией SQLite. Повторная загрузка того же source ID блокируется.

При ручном перемещении файла библиотека отмечает его как недоступный. Возобновление частичной загрузки, очистка завершённых карточек и восстановление удалённого оригинала с привязкой к существующему Track ID остаются для следующих версий.
