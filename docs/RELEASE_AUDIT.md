# Релизный аудит Music Player 0.1.0

Проверка 11 ноября 2026 года для демонстрации 17 ноября. Функциональное ядро «Моей волны» зафиксировано в `1993c4f` поверх Listening Feedback `f04f8b4`. Подготовка дистрибутива ведётся в `codex/release-0.1`.

## Дистрибутив

Результат сборки — `release/MusicPlayer-0.1.0-win-x64.zip` и файл контрольной суммы рядом. В ZIP входят EXE, Electron 45.3.0, приложение, зависимости, лицензии runtime-пакетов и синтетические MP3/FLAC. Для конференционного сценария выбран ZIP с ручной распаковкой, штатный формат распространения готовых бинарников Electron. Приложение загружается из `resources/app`. ASAR в этом пакете отсутствует. Новых зависимостей и изменений в lockfile нет. [Документация по упаковке Electron](https://www.electronjs.org/docs/latest/tutorial/application-distribution).

Проверенный ZIP занимает 160 262 398 байт. SHA-256 `838160ef51510668066457b6eacba7f8b05a8114cccf6992fd07877a97f04d1b`.

Манифест релиза содержит имя, версию и относительный путь входа. Runtime-пакеты раскладываются из локального store по lockfile. Служебные метаданные pnpm, исходный репозиторий и профиль пользователя в ZIP не включаются. При упаковке сохраняются sandbox, context isolation, запрет Node.js в Renderer, CSP, проверка IPC и локальный медиапротокол. [Чек-лист безопасности Electron](https://www.electronjs.org/docs/latest/tutorial/security).

## Рекомендации и пилот

С фиксированными каталогом, историей, временем и seed все три метода повторяемы. Проверены пустой и недоступный каталоги, один трек, короткая библиотека и исчерпание кандидатов. При одинаковых исполнителях алгоритм продолжает выдавать доступные уникальные ID. В конце списка он по одному возвращает самые давние исключённые позиции. При каждом новом запуске «Волны» Main использует актуальный снимок и новый seed. Формула ранжирования сохранена.

Синтетический прогон `node scripts/compare-recommendations.mjs` использовал seed 42, 13 доступных кандидатов и восемь позиций. У всех списков семь треков с известным исполнителем, три известных исполнителя и ноль дублей ID.

| Метод | Доля соседних пар одного известного исполнителя | Треки из недавней истории |
| --- | ---: | ---: |
| A. Случайный | 0% | 0 |
| B. По предпочтениям | 60% | 1 |
| C. Моя волна | 0% | 1 |

Доля соседних совпадений рассчитана по парам с двумя известными исполнителями. Совпадения с историей и дубли внутри списка считаются отдельно. Этот пример описывает поведение алгоритмов на одном снимке. Пилот с участниками не проводился. Скрипт экспорта проверен на отказе от пустого входа без создания выходного файла. Публикуемый агрегат можно получить после сбора фактических оценок. [Протокол и формат экспорта](PERSONAL_WAVE.md#экспорт-результатов-пилота).
