# Библиотека в Music Player 0.4.0

Поиск обновляет таблицу при вводе. Он ищет подстроку в названии, исполнителе или альбоме, игнорирует регистр и нормализует Unicode. Для композиции без названия используется имя файла, пустые теги отображаются как «Неизвестный исполнитель» и «—» соответственно. Поиск работает по текущему снимку библиотеки в Renderer.

Сортировка доступна по названию, исполнителю, альбому и длительности в обоих направлениях. Текст сравнивается с русской локалью и числовым порядком, поэтому «Трек 2» предшествует «Трек 10» при сортировке по возрастанию. При равенстве сохраняется порядок импорта. Пустые значения всегда в конце. Последовательная очередь идёт в порядке импорта, в том числе через строки, скрытые поиском. Ручной выбор начинает воспроизведение с выбранного трека. «Моя волна» использует полную доступную библиотеку.

Уровень громкости и состояние **Без звука** сохраняются в SQLite. При отключении звука ползунок сохраняет установленный уровень. При повторном включении применяется показанный процент. При переключениях, паузе и «Моей волне» используется тот же аудиоэлемент. После запуска настройка загружается до первого воспроизведения.

Для окна плеера отключено фоновое замедление Chromium, чтобы звук и переходы продолжались в свёрнутом окне при включённом режиме **Без звука**. Частые события позиции обновляют только шкалу воспроизведения. [Настройка окна Electron](https://www.electronjs.org/docs/latest/api/browser-window#page-visibility).

Исполнитель отображается под названием. В узкой области таблица скрывает второстепенные столбцы. При наведении на обрезанный текст подсказка показывает полный тег. Текущая строка выделяется сиреневым цветом.

## Выдача обложек

- Main выдаёт изображения по `music-player://app/artwork/<source-id>` в сессии плеера. URL содержит ID импортированного источника. Main при каждом запросе, включая попадания в кеш, сверяет канонический путь и идентичность открытого файла. После повторного импорта изменившегося файла новый ID источника заменяет прежний URL.
- Извлечение выполняется по запросу, по одному файлу за раз, из первых 8 МиБ проверенного дескриптора. Разрешены статические JPEG и PNG до 2 МиБ и 2048 пикселей по каждой стороне. Тип определяется по содержимому. Декодирование выполняется в sandboxed Renderer. Для отсутствующих, неподдерживаемых, повреждённых и недоступных изображений отображается нота. Для MP3 с начальным тегом ID3 больше 8 МиБ импорт пытается прочитать MPEG после тега и использует имя файла.
- Таблица создаёт элементы изображений для видимых строк и убирает их при прокрутке за пределы области просмотра. В панели плеера обложка запрашивается сразу. LRU-кеш в Main хранит до 256 результатов, включая отсутствие обложки, и до 16 МиБ данных. При переполнении удаляются самые давние результаты. Запрос отозванного или недоступного ID удаляет его запись. Кеш исчезает при завершении приложения, обложки на диск не сохраняются.
- Обложка, расположенная за пределами области чтения или в теге, который парсер не смог целиком разобрать в заданных пределах, заменяется нотой. При изменении файла нужен повторный импорт. Поиск, сортировка и таблица пока рассчитаны на каталог, помещающийся в память. Замеров на больших каталогах ещё нет.
