# Плейлисты

1. Откройте раздел **Плейлисты**, нажмите **Создать плейлист** и введите название. Название можно поменять кнопкой **Переименовать**.
2. Найдите композицию по названию, исполнителю или альбому, выберите её в списке и нажмите **Добавить**. Список показывает доступные треки, которых ещё нет в выбранном плейлисте.
3. Кнопки **↑** и **↓** перемещают композицию на одну позицию. Кнопка **×** убирает её из плейлиста. После нажатия **Удалить плейлист** подтвердите действие. Треки остаются в библиотеке, исходные файлы остаются на диске.
4. Кнопка **Воспроизвести плейлист** запускает очередь с первого доступного трека. Нижняя панель управляет паузой, перемоткой и переходами. После окончания последнего трека очередь останавливается. Чтобы применить изменения порядка к уже запущенной очереди, запустите плейлист снова.

При открытии раздела приложение проверяет доступность источников. Строки с отсутствующими файлами сохраняют своё место и помечаются как **Файл недоступен**. Плеер пропускает их. Если файл пропал уже во время работы с очередью, доступность проверяется при попытке открыть источник. Для изменённых файлов повторно импортируйте папку.

SQLite хранит плейлисты по UUID. У элемента составной идентификатор из UUID плейлиста и стабильного Track ID. Ограничения базы исключают повторы трека и позиции в пределах плейлиста. Смена порядка записывается транзакцией. Плейлист использует существующий плеер, поэтому прослушивания и пропуски входят в общую историю.
