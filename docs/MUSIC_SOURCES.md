# Music Sources

Раздел «Загрузки» принимает HTTPS-ссылки на `archive.org/details/<item>` или `archive.org/details/<item>/<file>`. Для сборника требуется ссылка на отдельную дорожку. Скачивание доступно для публичных оригиналов MP3 и FLAC до 150 МиБ с лицензией CC0, CC BY или CC BY-SA, указанной в Archive.org. Приложение проверяет метаданные источника и ограничения доступа.

1. Установите проверенный [yt-dlp для Windows x64](YT_DLP_INTEGRATION.md#локальная-установка).
2. Вставьте ссылку в разделе «Загрузки» и нажмите «Анализировать ссылку».
3. Проверьте лицензию и метаданные. Исправьте название, исполнителя, альбом или длительность. Можно оставить обложку источника, убрать её или выбрать локальный PNG/JPEG.
4. Нажмите «Скачать оригинал», затем «Добавить в библиотеку». «Показать файл» открывает расположение в Проводнике.

## Архитектура

- **Renderer и Preload** обмениваются снимками задач через именованный IPC. Обложки выдаются по ID задачи через внутренний протокол. Локальными путями и сетевыми адресами потоков распоряжается Main.
- **MusicSourceProvider** распознаёт ссылки, предоставляет анализ и скачивание. **YtDlpProvider** читает JSON встроенного Archive.org extractor. Нормализатор объединяет эти данные с Archive.org Metadata API.
- **DownloadManager** ведёт последовательную очередь. При подтверждении провайдер повторно проверяет разрешение, скачивает исходные байты и сверяет размер и SHA-1. [Менеджер загрузок](DOWNLOAD_MANAGER.md).
- **Library** использует существующую проверку кодека и контейнера MP3/FLAC. Файл становится локальным источником для воспроизведения, поиска, плейлистов, реакций, истории и «Моей волны».

## Происхождение метаданных

SQLite-схема 6 хранит исходные поля и пользовательские изменения отдельно в `external_recordings`. Ключ состоит из сервиса и ID записи. Для Archive.org этот ID содержит идентификатор элемента и имя оригинала. Разные записи с совпадающими названиями остаются самостоятельными. Отсутствующее поле источника имеет значение `null`. У явно очищенного пользователем поля в JSON изменений тоже есть значение `null`. Имя аккаунта, загрузившего материал, не используется как исполнитель. Если название отсутствует, библиотека показывает имя исходного файла.

Миграция создаёт и проверяет резервную копию. Повторное сканирование сохраняет Track ID, реакции и метаданные внешней записи. Обложка хранится в базе, а теги аудиофайла сохраняются в исходном виде.

## Расширение форматов и источников

HTMLAudioElement в Electron 45.3.0 воспроизвёл синтетические AAC в M4A и ADTS, Opus в Ogg и WebM и Vorbis в Ogg. Фикстуры созданы FFmpeg `9.0.2-essentials_build-www.gyan.dev` с проверкой SHA-256 архива `60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`. Для допуска в библиотеку потребуется расширить список форматов импорта, SQLite, MIME и проверки кодека. Playback Engine использует один HTMLAudioElement. [Проверенная сборка FFmpeg](https://github.com/GyanD/codexffmpeg/releases/expanded_assets/9.0.2).

Для нового источника добавьте реализацию `MusicSourceProvider`. Определите устойчивый ID, доказуемый признак разрешённой загрузки и список сетевых узлов. Проверьте перенаправления, закрытый доступ, дубли и реальный сквозной сценарий Windows на разрешённом материале. [Кандидаты](YT_DLP_INTEGRATION.md#техническое-исследование).

## Проверенный материал

Сквозной тест Windows использует CHASMA — «A Tone Poem», оригинальный MP3 с CC BY 3.0. Тест проверяет анализ и обложку, загрузку, исправление названия в библиотеке, воспроизведение и тот же Track ID после перезапуска. Условие запуска — переменная `MUSIC_PLAYER_YTDLP_EXE` с путём к проверенному yt-dlp `2026.10.26`. В обычном CI сетевой тест пропускается. Окружение проверки — Electron `45.3.0`, Node.js `24.22.1` и pnpm `11.25.0`. Сценарий загрузки выполнялся без `ffmpeg.exe`, `ffprobe.exe` и внешнего JS runtime. Для FLAC проверены правила допуска оригинала на фикстуре и локальное воспроизведение. [Исходная запись и обложка](https://archive.org/details/jamendo-184210), [License.txt](https://archive.org/download/jamendo-184210/License.txt), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
