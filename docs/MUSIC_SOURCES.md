# Music Sources

Раздел «Загрузки» принимает HTTPS-ссылки на отдельные записи Archive.org и SoundCloud. Для Archive.org поддержаны адреса `archive.org/details/<item>` и `archive.org/details/<item>/<file>`. Для сборника требуется ссылка на отдельную дорожку. Скачивание доступно для публичных оригиналов MP3 и FLAC до 150 МиБ с опубликованной лицензией CC0, CC BY или CC BY-SA.

1. Установите проверенный [yt-dlp для Windows x64](YT_DLP_INTEGRATION.md#локальная-установка).
2. Вставьте ссылку в разделе «Загрузки» и нажмите «Анализировать ссылку».
3. Для доступной загрузки Archive.org проверьте лицензию и метаданные. Можно изменить название, исполнителя, альбом, длительность и обложку.
4. Нажмите «Скачать оригинал», затем «Добавить в библиотеку». «Показать файл» открывает расположение в Проводнике. Для SoundCloud используйте официальный веб-интерфейс загрузки, описанный ниже.

## SoundCloud

Провайдер принимает публичный адрес `soundcloud.com/<аккаунт>/<трек>`. Адреса `www` и `m` приводятся к каноническому виду. Метки публикации `utm_*` из поддержанного списка и `si` удаляются. Поддержка ограничена отдельными публичными треками с полным адресом. Короткие ссылки, подборки, страницы профилей и приватные токены отклоняются.

Встроенный extractor SoundCloud в yt-dlp возвращает название, длительность, обложку, числовой ID и музыкальные поля, когда они опубликованы. Имя загрузившего аккаунта показывается отдельным полем. AAC/HLS и другие распознанные публичные форматы показываются справочно. Подписочные варианты, защищённые потоки и превью исключаются из этого списка.

Официальная загрузка оригинала SoundCloud требует входа на сайте и разрешения автора. На публичном треке 80M — «The Following» закреплённый yt-dlp вернул предупреждение о необходимости входа и варианты AAC/HLS 96 и 160 кбит/с. Сквозной тест Electron подтвердил карточку, обложку и сообщение об авторизации. Встроенной авторизации в Music Player пока нет. Полученный на сайте MP3 или FLAC можно импортировать штатным выбором папки. В этом сценарии идентичность основана на локальном источнике, а повторное сканирование этого файла сохраняет Track ID. [Проверенный трек](https://soundcloud.com/the80m/the-following), [скачивание на SoundCloud](https://help.soundcloud.com/hc/en-us/articles/115003448787-Downloading-tracks), [документация по потокам](https://developers.soundcloud.com/docs/api/guide#playing-tracks).

## Архитектура

- **Renderer и Preload** обмениваются снимками задач через именованный IPC. Обложки выдаются по ID задачи через внутренний протокол. Локальными путями и сетевыми адресами потоков распоряжается Main.
- **MusicSourceProvider** распознаёт ссылки и возвращает анализ. Провайдер Archive.org объединяет JSON extractor с Metadata API и реализует скачивание. **SoundCloudProvider** анализирует публичные ссылки встроенным extractor SoundCloud.
- **DownloadManager** выбирает провайдер по хосту и ведёт общую очередь. Возможность скачивания задаёт адаптер. При подтверждении Archive.org повторно проверяет разрешение, размер и SHA-1. [Менеджер загрузок](DOWNLOAD_MANAGER.md).
- **Library** использует существующую проверку кодека и контейнера MP3/FLAC. Файл становится локальным источником для воспроизведения, поиска, плейлистов, реакций, истории и «Моей волны».

## Происхождение метаданных

SQLite-схема 6 хранит исходные поля и пользовательские изменения отдельно в `external_recordings`. Ключ состоит из сервиса и ID записи. Для Archive.org ID содержит идентификатор элемента и имя оригинала. Анализ SoundCloud использует числовой ID трека, независимый от текста ссылки. Тест на синтетическом аудио подтвердил, что общий импорт сохраняет Track ID для повторного ключа после перезапуска и различает одинаковые ID разных сервисов. Разные записи с совпадающими названиями остаются самостоятельными. Отсутствующее поле источника имеет значение `null`. Явно очищенное пользователем поле присутствует в JSON изменений со значением `null`. Если название отсутствует, библиотека показывает имя исходного файла.

Миграция создаёт и проверяет резервную копию. Повторное сканирование сохраняет Track ID, реакции и метаданные внешней записи. Обложка хранится в базе, а теги аудиофайла сохраняются в исходном виде.

## Расширение форматов и источников

HTMLAudioElement в Electron 45.3.0 воспроизвёл синтетические AAC в M4A и ADTS, Opus в Ogg и WebM и Vorbis в Ogg. Фикстуры созданы FFmpeg `9.0.2-essentials_build-www.gyan.dev` с проверкой SHA-256 архива `60f467265b1e312373dbcd92200c2618a74850f98d3d078e94296bb3fa2047ba`. Для допуска в библиотеку потребуется расширить список форматов импорта, SQLite, MIME и проверки кодека. Playback Engine использует один HTMLAudioElement. [Проверенная сборка FFmpeg](https://github.com/GyanD/codexffmpeg/releases/expanded_assets/9.0.2).

Для SoundCloud на Windows отдельно воспроизведены синтетические PCM/WAV, AAC/M4A и локальный AAC/HLS с fMP4-сегментами. Проба HLS использовала полный набор сегментов, включая начальный, и тот же HTMLAudioElement. В 0.6.0 библиотека импортирует MP3 и FLAC. WAV и M4A проверены на уровне декодера. AAC/HLS показан в карточке как формат потока.

Для нового источника добавьте реализацию `MusicSourceProvider`. Определите устойчивый ID, доказуемый признак разрешённой загрузки и список сетевых узлов. Проверьте перенаправления, закрытый доступ, дубли и реальный сквозной сценарий Windows на разрешённом материале. [Кандидаты](YT_DLP_INTEGRATION.md#техническое-исследование).

## Проверенный материал

В Windows проверены анализ, скачивание, исправление названия, воспроизведение и восстановление того же Track ID для двух записей Archive.org.

- CHASMA — «A Tone Poem», оригинальный MP3 с CC BY 3.0. Тест также проверяет исходную обложку. [Запись и обложка](https://archive.org/details/jamendo-184210), [License.txt](https://archive.org/download/jamendo-184210/License.txt), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
- Artificial.Music & Storm Infinity — «Freefalling», оригинальный FLAC с CC BY 4.0. Тест проверяет, что ссылка на альбом требует выбора дорожки, а прямая ссылка на дорожку допускается. [Запись Archive.org](https://archive.org/details/SRS04107), [релиз артиста](https://artificialaryll.bandcamp.com/album/empty-vibes), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Для запуска сетевых тестов задайте `MUSIC_PLAYER_YTDLP_EXE` с путём к проверенному yt-dlp `2026.10.26` и запустите `pnpm test:desktop`. Обычный CI пропускает сетевые тесты. Окружение проверки — Electron `45.3.0`, Node.js `24.22.1` и pnpm `11.25.0`. Загрузки выполнялись без `ffmpeg.exe`, `ffprobe.exe` и внешнего JS runtime.
