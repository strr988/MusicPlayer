# Участие в разработке

Для воспроизведения ошибки и локального запуска используйте [инструкцию из README](README.md#разработка). Для изменений в коде и тестах сверяйтесь с [правилами репозитория](AGENTS.md).

1. Для ошибки опишите версию приложения и Windows, шаги воспроизведения, ожидаемый и фактический результат. Для предложения опишите пользовательский сценарий.
2. Создайте ветку от актуальной `main` в своём форке. Сохраните PR небольшим и опишите, что меняется для пользователя.
3. Выполните `pnpm build` и `pnpm test`. Для изменений импорта, IPC или плеера выполните `pnpm test:desktop`. Для упаковки выполните `pnpm package:windows` и `pnpm test:release` на Windows x64. Приведите результаты в PR.
4. Используйте синтетические файлы или материалы с подтверждённым разрешением на распространение. Удалите личные данные из диагностических материалов перед отправкой. Об уязвимостях сообщайте [приватно](SECURITY.md).
