# Проверка перед завершением

1. Сопоставь условия задачи и команды из корневого `AGENTS.md` с конкретными утверждениями для итогового отчёта.
2. Выполни нужные проверки на итоговом состоянии. Дождись завершения, прочитай вывод и проверь код выхода. Если после запуска менялись входы проверки, повтори её.
3. Сверь Git diff и список новых файлов с объёмом задачи. Для пользовательских сценариев проверяй результат на соответствующем уровне. Например, успешная сборка подтверждает сборку, а декодирование звука подтверждает десктопный тест.
4. Укажи команды и результаты. При сбое или ограничении среды укажи, какую часть результата ещё требуется проверить.
